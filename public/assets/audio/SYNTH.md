# SYNTH: shared sound cues

The six `synth_*.wav` files in this folder (`synth_rifle_shot`, `synth_hit_confirm`, `synth_slab_tick`, `synth_slab_tick_enemy`, `synth_match_end_win`, `synth_match_end_lose`) are **SYNTH** placeholders, synthesized sample by sample by `tools/audio/synth-cues.mjs` from oscillators, seeded noise, filters and envelopes; nothing is recorded, downloaded or AI-generated. **Licence:** original work, made in this repository, under the project's own terms, with no third-party audio in it. The format is 16-bit PCM mono WAV at 44.1 kHz, each file peak-normalised to -3 dBFS (so set playback level per cue in the mixer). To regenerate them, run `node tools/audio/synth-cues.mjs` from the repo root (Node only, no dependencies, no network). The output is deterministic and byte-identical every run, and `tests/unit/audio-cues.test.ts` checks this.
