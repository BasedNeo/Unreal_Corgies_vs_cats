## Lead snippets (paste-ready; other lanes' files)

### 1. `src/client/world/materials.ts` (world lane / E4): world materials go through the factory
This is what makes props, fences, terrain, foliage and water weathered and wet-aware. Before it lands, world props
only pick up the new soft ramp (through the shared `gradientMap`), not the hardened lighting. `labs/look.html`
(`&harden=1`) shows the result.
```ts
// imports: replace `import { toon } from '../style/style-webgpu.js';` with
import { toonMaterial } from '../style/style-webgpu.js';

type Params = { color?: number; vertexColors?: boolean; side?: THREE.Side; transparent?: boolean; opacity?: number; surface?: string };

/** New hardened toon material (style factory v2), uncached: callers set their own nodes. Surface preset default 'world'. */
export function toonFrom(p: Params = {}): THREE.MeshToonNodeMaterial {
  return toonMaterial({
    color: p.color ?? 0xffffff, vertexColors: !!p.vertexColors, side: p.side ?? THREE.FrontSide,
    transparent: !!p.transparent, opacity: p.opacity ?? 1, surface: p.surface ?? 'world',
  });
}
// toonNoInk() stays as it is (it clears the ink flags on toonFrom's material).

// createTerrainMaterial: the ground preset (no grime/wear, wet sheen, reflective puddles)
  const material = ink ? toonFrom({ surface: 'ground' }) : toonNoInk({ surface: 'ground' });
// createFoliageMaterial:
  const m = toonNoInk({ vertexColors: true, side: opts.side ?? THREE.DoubleSide, surface: 'foliage' });
// createWaterMaterial:
  const m = toonNoInk({ transparent: true, opacity: 0.86, surface: 'water' });
```
Optional, one puddle mask instead of two: the terrain already paints colour-only puddles with ripple rings (`if (detail)`
block). To make exactly those the reflective ones, hoist the mask and hand it to the material:
```ts
  // eslint-disable-next-line @typescript-eslint/no-explicit-any -- TSL node types are too narrow (as elsewhere here)
  let puddleMask: any = float(0);                        // before `if (detail) {`
  ...  puddleMask = puddle;                              // inside, after `const puddle = ...`
  const material = ink ? toonFrom({ surface: 'ground' }) : toonNoInk({ surface: 'ground' });
  (material as unknown as { puddle: number }).puddle = 0;                   // no factory puddles (compile-time)
  (material as unknown as { roughnessNode: unknown }).roughnessNode = mix(float(0.92), float(0.035), puddleMask);
  (material as unknown as { wetNode: unknown }).wetNode = puddleMask;
```
Props that want other presets pass one (e.g. `toonFrom({ vertexColors: true, surface: 'wood' })` for fences and
decks, `'metal'` for terminals, `'plastic'` for toys). Presets: `SURFACES` in `style-tokens.js`.

### 2. `src/client/world/world-view.ts`: exact wetness for the look
```ts
    if (changed) { Object.assign(applied, next); sky.setWeather({ ...next, wet: w.wet }); }
```
Without it the sky estimates wetness as `min(1, rain * 2.5)`. That is right in rain and storm but too dry while it
clears.

### 3. Floodlights (E4 places them: bases, watchtowers, terminals)
```ts
import { createFloodlights } from '../style/floodlights.js';
// createWorldView, after the props:
const floods = createFloodlights({ tier: toQualityTier(q) });
for (const f of data.floodlights ?? []) floods.add({ pos: f.pos, target: f.target });   // all of them at build
root.add(floods.group);
// update(): floods.update(camera);     dispose(): floods.dispose();
```
`pos` is the lamp head and `target` the ground point it lights (the pool centre, on the surface: `surfaceAt(...).y`).
Heads on 7–10 m masts read best. Never add one after the first frame: a new light recompiles every material.

### 4. Characters (K2): already adopted in K2's working tree
K2's in-progress files already use this API. `mesh-builder.ts` writes the `surface` vec4 as [rough, metal, grime,
wear] from `SURFACES`, and `index.ts` / the bosses call `toon({ vertexColors: true, surfaceAttr: true, surface: 'fur' })`
and `surface: 'weapon'`. The layout matches the factory exactly. Two notes for integration:
- `mesh-builder.ts` sets the attribute only `if (this.anySurf)`. That is safe: on a geometry without `surface`, a
  `surfaceAttr` material falls back to its own values (a separate program, tested), instead of reading zeros, which
  would be a mirror.
- The `as Parameters<typeof toon>[0]` casts can go: `toon()`'s JSDoc `ToonParams` now lists every new field.
- Palette: `colors.ts` reads `hazardOchre`, `oxblood`, `charcoal` through `tok()`; they now exist. Also available:
  `camoBlack`, `underSuit`, `brass`, `mud`, `gunmetal`, `steel`.
- For reference, the pattern (if another merged mesh needs it):
```ts
// mesh-builder.ts: keep a `surf: number[]` next to `col`, push (rough, metal, grime, wear) per vertex, e.g. from
// SURFACES.fur / SURFACES.armor / SURFACES.cloth by part; build():
g.setAttribute('surface', new THREE.Float32BufferAttribute(this.surf, 4));
// index.ts
const bodyMat = toon({ color: 0xffffff, vertexColors: true, surfaceAttr: true, mud: 0.5 });
```
Without a per-vertex surface, use `toon({ color: 0xffffff, vertexColors: true, surface: 'fur' })` for the body and
`surface: 'armor'` on any separate plate mesh. The mud band (`mud`) is measured from the mesh's local y = 0 (the
feet), so it must stay 0 for meshes whose origin is not the floor (weapons, hats).

### 5. Weapons (X3)
`toon({ color: 0xffffff, vertexColors: true, surface: 'weapon' })` for gun bodies (worn metal edges, grime). Your
muzzle pulse lights sum with the floodlight budget (see Budgets).

### 6. Optional (shared, gameplay-visible): matches start later in the day
`src/shared/world/weather.ts` › `timeOfDayAt`: `const tod0 = 0.40 + 0.06 * hash2(1, 2, s);` → `0.60 + 0.06 * …` starts
matches in the late afternoon and runs them into dusk. The sky already rakes all day (42° max), so this is taste, not
a requirement; night then comes sooner in long sessions.

### 7. ARCHITECTURE.md (lead)
> **Style v2 (W7 S4).** `toon()` returns `HardenedToonMaterial` (a `MeshToonNodeMaterial` subclass with its own
> lighting model and TSL weathering); `toonMaterial()` is the uncached variant for code that sets nodes. The sky
> drives two shared uniform sets, `STYLE_ENV` (reflection colours) and `STYLE_WEATHER` (wet, rain, dark). Material
> detail is a build-time tier knob (`setStyleDetail`, set by `createRenderContext`). Floodlights:
> `style/floodlights.js`, a fixed real-light budget per tier plus instanced fake pools.

**What it reads as, after:**
- **Clear:** overcast late afternoon, not noon. Low raking light and long shadows, broken slate cloud, haze layering the
  neighbours' houses. The olive lawn, weathered wood and grimy props sit under a gritty grade with grain and vignette.
  It is still clearly daytime and readable; the sunny picnic is gone.
- **Storm:** a dark slate sky with heavy billows. The wet lawn goes dark, with a sheen toward the horizon; puddles
  mirror the sky; the rain is thin and steel-grey, with a faint far sheet. Sodium pools (look lab) warm the ground and
  catch in the wet surfaces. The garden and cats bookmarks come closest to the mood board.
- **Teams:** the lineup reads by team at 6.5 m in every shot, in clear, storm and on low: blue + gold corgi trims,
  crimson + black cat trims. The grade's chroma protection keeps them saturated while the yard desaturates.
- **Low tier:** the same mood without shadows or bloom. Flatter light, but the fake floodlight pools carry the warmth.
- **Still v1-bright, not mine to change:** `WORLD_EXTRA` colours (pumpkins, flowers, paddling pool, duck) and the clover
  decals. Snippet 1's `fade` on world/foliage presets tones them down; E4 owns the palette entries.
- **Demo floodlights:** each bookmark's demo lamp sits ahead of the camera, so from other bookmarks they appear as
  bright lamps in the sky (the "moon" in center/cats). E4's real placement on masts at bases will not do this.
