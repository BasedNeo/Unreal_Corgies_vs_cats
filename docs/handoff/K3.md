# K3 handoff: hardened squads, veteran rank, under-suit lift (Wave 9, char-3)

**Status:** done; nothing is staged or committed (the lead integrates). Measured against a clean snapshot of HEAD
(`38db372` for the "before" images and numbers, `8b171aa` = G4a for the final tests) plus only the K3 files.

What K3 adds:
- **Two PvE squads for Yard Skirmish:**
  - **alley-cat raiders**: light, fast, flanking, 60 hp, a sidearm, a scavenged kit.
  - **tabby heavies**: slow shield-bearers, 180 hp, a frontal guard, a bin-lid shield and heavy plates.

  Each has an archetype, its own kit on the shared rig and wave slots. The difficulty band holds over 24 seeds.
- **The veteran rank:** a `rank` look slot (corgi sergeant's chevrons, cat commander's medal).
  - It unlocks at level 10 through the existing profile, XP and locker flow and persists in `cvc.profile`.
  - It rides hello and the `look` message, and another client draws it as the K2 veteran kit plus the insignia.
  - The simulation plays out bit-identically with or without it.
- **The under-suit lift and team elements:**
  - The field suit goes from sRGB luma 35 → 71 (corgi) and 43 → 69 (cat).
  - The team armband now covers the whole upper sleeve.
  - A rear team strobe is added on assault, breacher, warden and skyraider.
  - Veterans' thigh plates carry a team shell.

  The team read is higher or equal on all 48 kits. **At 35 m under the lab's dusk rig the suit barely moves the
  image.** Value at that range is lighting-limited, as measured in §5. P4's rim light is the lever.

No draws were added per character. Every budget holds with the 20-triangle margin. K1 class distances are exactly
the same or higher on every seed and species.

## 1. Squads: the design (game-design-psychology: read at a glance, ask for different answers, no player power)

| | Alley-cat raider (`alley_raider`, "Alley Cat") | Tabby heavy (`tabby_heavy`, "Heavy") | For scale: grunt / kitten / brute |
|---|---|---|---|
| Question it asks | "Watch your flank": it circles in close and strafes hard | "Get round it": the guard eats frontal fire, and it turns slowly | |
| Class kit (weapon model) | infiltrator (snap pistol) | assault (squeaker rifle) | assault / infiltrator (claw) / warden |
| hp | **60** | **180** (EHP from the front 300) | 120 / 45 / 320 |
| Speed | ×1.15 (run 7.4 m/s) | ×0.78 (run 5.0 m/s) | 1 / 1.2 / 0.85 |
| Engagement | 5–12 m, strafe 1.0, hop 0.4/s, no retreat | 9–20 m, strafe 0.12, no jumps, no retreat, turn rate 3.2 rad/s (grunt 5.5) | |
| Aim, fire | reaction 0.45–0.7 s, error 11° → 3.4°, bursts 1–2, pauses 0.6–1.0 s | reaction 0.5–0.75 s, error 8° → 2.4°, bursts 4–8, pauses 0.5–0.9 s | |
| Ability | none (`abilityUse 0`: no cloaked PvE flankers) | 0.3 | |
| Guard | none | **−40 % damage from attackers within 55° of its facing** | |

**The frontal guard.**
- The data lives in `archetypes.ts` (`guard: { reduce, arc }`, the pure `guardFactor`).
- It is read by one guarded line in `combat/damage.ts`, for PvE bots only:
  ```ts
  if (!self && dst.ai && dst.combat?.pve) { const a = sim.entities.get(src.id); if (a) amount *= guardFactor(dst.ai.arch, dst.yaw, dst.pos.x, dst.pos.z, a.pos.x, a.pos.z); }
  ```
- It uses the attacker's position, so a blast from a frontal shooter counts as frontal.
- A crossfire or a flank does full damage, and the heavy's slow turn gives a flanker time.

**Waves** (`match/config.ts`; no wave grew; wave 1 unchanged for the FTUE):

| Wave | Before K3 | K3 |
|---|---|---|
| 1 | grunt 3 (max alive 2) | same |
| 2 | grunt 4, kitten 2 (max 4) | grunt 3, **raider 2**, kitten 1 (max 4) |
| 3 | grunt 4, sniper 1, kitten 4 | grunt 3, **heavy 1**, sniper 1, kitten 3 |
| 4 | grunt 5, sniper 2, brute 1, kitten 4 | grunt 3, **raider 2, heavy 1**, sniper 2, brute 1, kitten 2 |
| 5 FINAL + Vac-Tank | grunt 3, kitten 3 | grunt 2, **raider 2**, kitten 2 |

**How the client knows a squad (no protocol change).**
- `squadKitFor(class, maxHp)` maps the class and max hp, which every snapshot carries, back to the kit.
- A squad's hp is unique for its class. The test checks every class hp, every Upgrade Core `maxHp` buff and every
  other archetype.
- PvE bots take no pickups and never swap kits, so the kit is stable for the whole life.
- `maxHp` is sent unrounded on the wire.
- `EntityViews` builds the squad kit with `createCharacter({ …, squad })`, so the lead's `AvatarOptions` needed no
  change.

## 4. Veteran rank (the rank slot)

- **Content** (`cosmetics.ts`):
  - `rank` joins `LOOK_SLOTS`: `rank_none` ("No Rank", default, both species), `rank_sergeant` ("Sergeant's
    Chevrons", corgi, **level 10**), `rank_commander` ("Commander's Medal", cat, **level 10**).
  - Helpers: `VETERAN_RANKS` and `wearsVeteranRank(look, species)`, which is sanitized.
  - `defaultLook` / `resolveLook` fill `rank: 'rank_none'`.
  - `randomLook` returns `rank_none` without an RNG draw, so every existing bot look is unchanged. Bots' veterans stay
    `isVeteranSeed`.
- **Unlock, locker, persistence:** the profile code is content-driven, so no profile file changed.
  - Level 10 (3,100 XP) unlocks both ranks through `evaluateUnlocks`, and the reward card lists them.
  - `nextLevelUnlock` shows them as the next reward once the level-6 looks are earned ("always show the next reward").
  - The LOCKER gets a RANK tab through `LOOK_SLOTS` with a glyph per item (`rankGlyph`: gold chevrons, a battered
    medal, an empty sleeve).
  - Equipping below level 10 is refused ('locked'), and another species' rank is refused ('species').
- **Worn online:**
  - hello `looks` → guard → roster `look` (the snapshot is unchanged);
  - `EntityViews` picks `veteran` from `wearsVeteranRank(roster look)` for players and from `isVeteranSeed` for bots;
  - a LOCKER equip mid-session is worn from the next spawn (the view rebuilds as the other kit).
- **What it looks like:** the K2 veteran kit (bigger plates with a rank stripe, crest or badge, second scar, the cat's
  eye patch) plus the insignia:
  - corgi: **gold chevrons** on both upper sleeves (two on the hero tier, one slimmer one at the NPC tier);
  - cat: a **battered brass medal** on a team ribbon, high on the right chest.

  The K2 crest or badge above is the "cap badge". Veterans' thigh plates now carry a **team shell**, so the insignia
  never lowers their team read (§6).
- **No combat power:** looks never reach stats. A test runs the same room (2v2 bots, a scripted human firing for 12 s)
  with and without the rank; **every snapshot is identical**.
